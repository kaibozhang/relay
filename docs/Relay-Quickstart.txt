续页 Relay — Windows 本地续做工具

开始
1. 解压完整文件夹，双击 Relay.exe。不需要浏览器、账号或联网。
2. 本包是便携模式（portable.txt）：你的数据会在程序旁的 Data 文件夹。
3. 更新程序时保留 Data。请不要只复制一个 EXE，也不要把旧 Data 覆盖掉。

最短的一次使用
正在工作时 Ctrl+Alt+Space → 写一句具体的下一步 → Ctrl+Enter。
比如“核对报告第3页收入数字”，而不是“继续做报告”。
回来后按 Ctrl+Alt+R，或从托盘打开续页。续做条会把下一步留在工作旁。
可以附加文件、文件夹或网址；只保存引用，不复制原文件。
每完成一小步，点击“留个进展”，同时写好接下来做什么。

数据是本机磁盘文件，不是浏览器缓存
Data/vault.json：续做卡、资源引用、进展和设置。
Data/vault.json.bak：成功保存前的上一版。
Data/focus.json：当前专注计时。恢复程序后继续结算。
Data 中的文件未加密。请定期在设置中导出 JSON，并另存到安全位置。
完整卡片 JSON 不包含正在运行的计时文件；要完整搬家，完全退出后复制整个 Data。
原始文件的路径如果变化，需编辑卡片更新；引用不是原文件备份。

顺手入口
- 托盘右键：捕捉、继续、打开主窗、退出。
- 任务栏悬停：Windows 缩略图与快捷按钮；右键跳转任务由系统管理。
- 设置：自定义两组全局快捷键，若占用会显示并尝试恢复旧绑定。
- 设置：可选启用文件右键、发送到、开始菜单，均可撤销。
  这些动作需要系统允许；本次测试宿主曾拒绝相关目录/注册表写入。
  失败会明确提示，不会偷偷提权或关闭安全策略。

安全与边界
不扫描文件，不后台读取剪贴板，不记录屏幕/窗口/按键历史。
只在你明确粘贴时读取剪贴板，只在你选择后打开资源。
程序、脚本、快捷方式等只定位，不直接执行；普通文档也请确认可信。
不恢复其他软件没保存的编辑内容、光标、窗口布局。
没有手机端、云同步或账号。Android 按本轮要求暂缓。
晚22点至早8点不提醒；程序未运行时不发提醒，不装后台服务。
关闭主窗可能留在托盘，完全退出请用托盘“退出”。

迁移旧版留白
先在旧网页里导出完整 JSON，再在本程序设置点击“从旧版留白迁移”。
会预览转换结果再追加；长正文拆成连续卡，回收站不迁移，旧专注成绩不伪造到新程序。
不会读取浏览器资料，也不会自动访问旧笔记中的链接。

卸载
先在设置撤销曾启用的系统入口；从托盘退出；删除程序文件夹前移走要保留的 Data。
未签名软件可能受 SmartScreen 或企业策略限制。请核实来源，不要关闭安全保护。

本项目没有宣称独创或比成熟工具一定更高效。
如果现有笔记/任务工具已经让“留下一步、回来继续”足够顺手，就不用重复维护。
真正值得保留的，是少找一次现场，而不是多一个软件。
