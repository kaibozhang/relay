# 已知限制，不用小字隐藏

1. **只有 Windows x64。** Android 按用户要求暂缓，没有手机安装包或同步。
2. **这是续做线索，不是系统现场快照。** 不恢复其他软件没保存的正文、选区、光标、窗口排列、登录状态。
3. **数据是明文。** 本地并不意味着加密；不适合代替密码保险箱。
4. **全局入口需要程序在运行。** 不默认自启，不安装服务；退出后快捷键和提醒就不工作。
5. **系统整合受权限和 Windows Shell 决定。** 本次宿主的注册表和真实SendTo位置写入被拒绝。程序提供显式入口、失败提示和撤销，不能保证企业策略允许，也不会绕过保护。
6. **未签名。** SmartScreen可能提示；哈希只核对文件一致性，不证明发布者身份。遵循组织策略，不建议关闭安全保护。
7. **不访问网络路径或重定向资源。** 网络映射、UNC、符号链接/目录联接等被拒绝，以免看一张卡就发起外部认证或跟随意外目标。
8. **文档默认应用仍有风险。** 程序/脚本仅定位；普通文档交给系统关联程序，用户仍应确保文件可信。
9. **备份分两层。** 完整卡片JSON含卡片与设置，不含进行中的计时文件和新卡草稿目录。完全退出后复制整个Data才保留完整本机状态。引用的原文件另行备份。
10. **上一版不是无限历史。** 单个.bak可恢复最近有效状态，不承诺断电/磁盘损坏都能救回；2.1仅新卡捕捉有明示可关闭的草稿恢复；最近未暂存的按键、已有卡编辑和进展草稿仍可能丢失。
11. **容量是有边界的。** 5000张卡、每卡100引用、标题200字符、下一步2000字符、上下文50000字符，主仓库最多32MiB；正文迁移超限会分片或拒绝，不悄悄截断。
12. **可访问性尚非完整认证。** 焦点/中文名称/URL按键/静态对比度有测试；实际读屏、所有中文输入法、高对比度运行时切换、所有DPI与多屏未全面验证。
13. **没有声称比成熟工具普遍更好。** 如果Task Coach、QOwnNotes、CherryTree或你的笔记模板已经把接续工作做得顺手，就不必多维护一个工具。
14. **导出文件名有限制。** 为防别名覆盖数据，不能导出为vault.json、focus.json及其派生名、.relay.lock，或带~的短路径样式文件名。请选择新的普通文件名。
15. **可信同用户环境。** 路径检查与锁防意外，不是对抗相同权限恶意程序路径交换的安全沙箱。
