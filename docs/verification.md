# 留白 / Lumen 验证报告

## 最终结果

- **29 / 29 核心测试通过**：原生 Node 内置 `node:test`，不是仅语法检查。
- **26 / 26 浏览器验收通过**：真实 Chrome 无头模式，CDP 驱动，本地 file URL，独立测试资料目录。
- **脚本语法检查通过**：应用、核心、浏览器测试脚本。
- **核心测试额外在 `TZ=America/New_York` 与 `TZ=UTC` 的独立 Node 进程运行，各 29 / 29 通过**。默认本机时区运行也通过。
- 浏览器测试捕获到的应用 HTTP(S) 请求：**0**；未处理浏览器异常：**0**。这不等于监控了浏览器本身或系统组件的所有网络活动。

浏览器原始记录：[browser-test-results.json](<browser-test-results.json>)。

## 真实浏览器验证范围

1. 初始工作台、示例内容和零伪造专注成绩。
2. 1440px 桌面宽度没有横向溢出。
3. 快速捕捉保存，刷新后仍在。
4. 创建编辑与 Markdown 预览；脚本、危险 URL、远程图片不会执行或加载。
5. 笔记删除进入回收站，并可恢复。
6. 任务创建、完成和筛选。
7. 星图有真实笔记节点与连接。
8. 专注开始、暂停、恢复、刷新与主动终止。
9. 命令面板搜索和导航。
10. 每日目标保存与完整 JSON 往返。
11. 模拟中文 composition 输入时，不替换正在输入的搜索框。
12. 合法的特殊标签在只编辑正文时不被重写。
13. 过期计时刷新后只结算一次。
14. 已记录但残留的计时自动清除，不重复记录。
15. 损坏存储保留原始内容，提供恢复出口。
16. 10,000 篇笔记上限下，新建被拒绝，现有备份仍有效。
17. 计时完成不丢失快速捕捉草稿或光标位置。
18. 命令面板键盘选择与实际聚焦按钮响应。
19. 模拟存储配额写入失败，显示警告，内存修改仍能导出；恢复写入后可保存。
20. 坏备份拒绝且不改变数据；合法备份确认后恢复。
21. 导入确认期间存储变化时，拒绝覆盖。
22. 检测到多标签页修改时阻止静默覆盖。
23. 390px 手机宽度下六个主要页面均无横向溢出。
24. 手机抽屉转移焦点、隔离背景、Esc 关闭并恢复焦点。
25. 应用没有 HTTP(S) 请求。
26. 无未处理浏览器异常。

## 核心测试范围

UMD/CommonJS API、种子内容、快速唯一 ID、不可变数据、完整备份、恶意字符串、严格 schema、重复 JSON 字段、原型字段、日期/数值/类型/容量限制、链接去重、10,000 重名笔记不会产生全连接爆炸、UTF-8 备份字节上限、截止时间/暂停/恢复/幂等结算、专注上限保留原状态、本地周统计及跨年/闰日/DST 邻近日期。
