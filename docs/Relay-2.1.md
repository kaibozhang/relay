# 续页 2.1：更安静地继续，少写一份记录

## 这轮改进

1. **全局继续不再强制显示管理页。** Ctrl+Alt+R、托盘继续和冷启动 --resume 直接显示续做条；没有可继续的卡片时，只开捕捉窗口。
2. **下一步优先，进展选填。** 更新下一步不再强迫写回顾，也不会生成空白检查点。空进展且下一步没变化会明确提示，不假称已保存。
3. **新卡草稿本地恢复。** 捕捉时明示本地明文暂存，停笔后约0.8–1.6秒写入；可关闭本次暂存，也可“暂存并收起”。下次从主界面“未提交草稿”恢复，正式保存不重复建卡。

## 草稿边界

- **只适用于新卡捕捉**。编辑已有卡片、更新下一步/进展仍是正式保存事务，失败保留窗口内容，但没有磁盘草稿恢复。
- 暂存在当前仓库 drafts 子目录，明文JSON，最多50份、单份1MiB；空间、权限或内容不合规时明确显示失败，原窗口保留。
- 状态“草稿已暂存”不等于已正式保存。最近尚未达到暂存时机的按键仍可能在崩溃时丢失。
- 正式保存或明确放弃清理暂存；关闭本次自动暂存会清除本次已有暂存。关闭草稿列表不删除任何草稿。
- 不新增屏幕、窗口、剪贴板监听，不上传。草稿不含在完整卡片JSON导出中；完全退出后备份整个Data才包含草稿。
- 损坏草稿保持原样并显示警告，不自动删错。发现同ID已经正式提交的剩余草稿不会自动删除或再次提交，会提示先查看正式续页，再明确放弃草稿。

## 兼容与回退

主仓库格式仍为version1，不迁移或重写用户数据。旧2.0包保留为 [2.0备份](<../dist/Relay-Windows-x64-v2.0.0.zip>)。更新仍保留Data；2.0无法显示2.1草稿，但正式卡片可继续读取。
