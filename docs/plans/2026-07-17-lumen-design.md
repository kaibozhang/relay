# 留白 / Lumen — 设计与实施计划

**Goal:** 让一个空文件夹变成每天可以回来使用的私人工具。

**Architecture:** 零运行时依赖、纯 HTML/CSS/JavaScript，本地优先的单页应用。数据核心以 UMD 形式同时支持浏览器与 Node 测试；UI 只使用安全 DOM API/转义文本。通过 file:// 可直接打开，所有静态资源相对路径加载。

**Tech Stack:** 原生 JavaScript、CSS、SVG、localStorage、Node 内置测试。

## 产品与验收
- 中文工作台：快速捕捉，今日任务，最近笔记，7 天专注记录。
- 笔记：创建、编辑、搜索、标签、置顶、回收站、Markdown 安全预览、[[标题]] 链接与反向链接。
- 星图：基于真实笔记链接的 SVG 网络，可点击进入笔记、搜索与筛选。
- 任务：添加、完成、删除、日期、优先级，专注可以绑定任务。
- 专注：25/45/60 分钟、自定义时长、暂停/继续、终止；用绝对时间计算，刷新不丢失。完成后记录专注分钟；无虚假的初始成就。
- 数据：版本化 JSON，校验后导入，备份导出，存储错误明确提示；不联网、不接入账号。
- 键盘：Ctrl/Cmd+K 搜索导航，Esc 关闭模态框，输入控件可键盘操作，移动端可用。

## ADR 001：静态应用而非 Electron / 服务端应用
选择静态本地应用，换取零安装、易保留、离线可用。舍弃后台系统通知、多端同步和跨文件夹自动一致的存储。浏览器数据按环境隔离，因此显式备份是核心功能。

## ADR 002：localStorage 而非 IndexedDB / SQLite
文本工作台的数据较小，localStorage 足够且能直接在 file URL 使用（浏览器策略可能限制）。提供导出、严格导入及存储失败提示；上限与隐私模式风险在文档说明。若持久化不可用，继续内存模式而不伪称已保存。

## ADR 003：安全、有限的 Markdown
不执行 HTML、不加载远程图片，不引入第三方脚本。支持标题、段落、列表、代码、强调、链接、双链，链接协议只允许 http/https/mailto。

## 数据流
UI 事件 → Core 纯函数更新 → Store 保存并报告错误 → 对应视图重绘；计时器单独 tick，避免编辑器丢焦点。

## 实施任务
1. 创建 core.js 与 tests/core.test.cjs：先写模型/搜索/链接/导入/计时测试，运行 node --test tests/core.test.cjs；实现到通过。
2. 创建 index.html 与 styles.css：固定侧栏、暖纸主区、深绿专注卡；响应式、reduced-motion、focus-visible。
3. 创建 app.js：总览、笔记编辑器、任务筛选、可点击星图、专注计时、命令面板、设置备份。
4. 整合测试：语法检查、Node 核心测试、浏览器真实交互（环境允许时），保存测试结果，不把未执行测试算通过。
5. 创建 README.md 与可离线打开的交付入口；验证所有功能入口不为空，记录局限。

## 风险与处理
- localStorage 禁用/配额：可见警告 + 内存工作 + 导出 JSON。
- 导入损坏：逐项校验，在写入前拒绝，不覆盖现有数据。
- 意外删除：笔记进入回收站，可恢复；危险操作确认。
- 多标签页：storage 事件同步或明确冲突提示。
- 计时不精确：以 deadline 为准，浏览器关闭后重新打开也能结算一次。

用户已经批准方向与后续自主决定细节；采用当前会话并行开发。
