# 续页 Relay · Windows 使用指南

## 一页上手

**中断 → 留下下一步 → 带上资源引用 → 回来，在工作旁继续。**

续页把“刚做到哪、下一步做什么、资源在哪”放在同一张卡里。与待办、笔记并用的理由，是独立捕捉入口和工作旁的续做条可能减少重新找线索的步骤；不是取代已有工具，也不是已测出的竞品优势。现有工具已经顺手，就不必重复维护。

### 打开，然后试三步

Windows 程序：[Relay.exe](<../dist/windows/Relay.exe>)。当前路径已有较早发布产物，最终版将重新发布到同一路径；源码新增功能不能仅凭旧文件存在就视为已交付。自包含 .NET 发布包无需另装 .NET、浏览器宿主或 WebView；保留完整发布目录。未签名程序可能触发 SmartScreen，请先核实来源、遵循组织政策，不要关闭安全保护。

下面只是“写报告时被打断”的抽象说明，不是预置用户数据。主窗口“如何让它顺手”打开帮助；阅读帮助不会捕捉或创建示例。

1. **离开前留一个动作。** 点击“留下续做卡”或帮助中的“留自己的第一步”。写“核对报告第3页收入数据”，不要只写“继续做报告”；补一句刚做到哪里。用自己的内容填写。
2. **带上资源引用，再确认保存。** 主动选取／拖入文件或文件夹，或添加网址；只保存路径／链接，不复制文件。剪贴板只有点击粘贴时才读取。看到保存成功确认后再离开。
3. **回来在工作旁继续。** 选择续做卡，选择需要的资源，再打开续做条。“留个进展”可同时记录刚完成的一步和新的下一步，两者一次保存；写入失败保留草稿。

| 场景 | 默认入口 |
| --- | --- |
| 全局留下下一步 | Ctrl+Alt+Space |
| 全局续做最近一张 | Ctrl+Alt+R |
| 主窗口内新建／搜索 | Ctrl+N／Ctrl+F |
| 关闭帮助 | Esc 或“关闭” |

两组全局快捷键可在“空间与系统设置”自定义，**以当前设置与注册状态为准**；程序须在运行，热键须注册成功。冲突时换组合或用主窗口／可用托盘入口。

**先记住三件事：** 数据未加密，保存在本机；未提交草稿不等于已保存；续页不能恢复其他应用未保存的编辑内容或窗口布局。它无需账号、不监控后台工作，Android 暂缓。详细边界见下方。

## 按需查阅：资源、提醒与专注

- **资源组：** 默认全部不勾选，每次最多选择 10 个；明确点击才提交打开请求，打开前再次检查。程序／脚本只定位、不执行。安全检查不等于内容可信；打开网址仍需系统浏览器，文档仍需对应应用。资源被移动、删除或路径变化后需重新定位。
- **稍后提醒：** 本机时间 22:00–08:00 为安静时段；到期卡仍可在队列中找到。程序运行且系统醒着时检查，多个到期项合并一次提醒，先持久化确认状态再通知，避免重启反复打扰。它不是系统闹钟：退出、睡眠时不会唤醒系统提醒；系统屏蔽通知或确认后恰好退出时，也不保证看到通知。
- **专注：** 本机计时状态可跨重启保留，完成待记录状态可在后续启动处理；这不代表应用关闭时仍持续显示或通知。托盘驻留用于快捷键、计时与提醒，不会自动采集窗口、文件、浏览记录或剪贴板。

## 本地保存与备份

发布包默认采用便携模式：程序旁的 `portable.txt` 标记使仓库存放在同目录的 `Data` 文件夹；发布脚本默认保留已有 `Data`。没有此标记时使用 `%LOCALAPPDATA%\Relay\Vault`。以帮助／设置显示的完整路径为准；也可显式指定：

```powershell
.\Relay.exe --vault "D:\MyRelayData"
```

| 当前仓库中的文件名 | 用途 |
| --- | --- |
| `vault.json` | 卡片、资源引用、进展与设置 |
| `vault.json.bak` | 成功更新时保留的上一版；首次保存不一定存在，不是完整历史 |
| `focus.json` | 本机专注计时及待记录完成状态 |

确认保存、修改状态等操作会自动写入本地磁盘；**只有写入成功并收到保存确认，才算保存**。失败时捕捉／进展编辑草稿留在窗口，可处理权限、空间或占用后重试；草稿不是崩溃恢复备份，直接退出或断电仍可能丢失。主文件损坏时会尝试有效备份，无法安全恢复时可进入只读状态；先保留整个目录，不要覆盖原文件。

这些是**未加密的明文 JSON**，不是浏览器存储，也不是云端保险箱。能访问目录的用户或软件可能读取它；请定期备份到另一安全位置。

### Relay 备份恢复，与旧版迁移是两件事

**Relay → Relay：** 设置中的“导出完整备份”导出卡片、进展和设置，**不包括独立的专注状态文件**。从备份恢复会替换当前内容，不是合并；先导出当前仓库再确认。JSON 可阅读和转换，但导入须通过字段、版本与容量校验。换机时退出程序后另存完整仓库副本，引用的原始文件也要另行迁移；不要在运行中手动改写仓库或让两个进程同时操作它。

**旧版留白 Lumen v1 → Relay：** 设置中的“从旧版留白迁移…”只读取你明确选择的完整 JSON 导出，不读取浏览器存储。先展示迁移摘要，再由你确认**追加**，不替换现有卡片；重复导入会产生重复卡片。

- 导入笔记与任务，跳过回收站笔记；长正文分成续页保留，不截断，完整原始标题与日期保存在上下文。
- 忽略 `sessions`（专注记录）、`timer`（计时器）、`settings`（设置）；不伪造恢复次数、专注统计或历史进展。
- 链接、HTML、路径仅作纯文字，不访问、不自动附加资源；截止日期仅保留为文字，不新建提醒。笔记的默认下一步须自行改成具体动作。
- 迁移会校验原始数据与合并后容量；失败不提交当前仓库，也不修改旧备份。

## 系统入口与卸载

系统右键、发送到等可选入口只在你主动启用时尝试安装；启动与阅读帮助不会自动修改注册表。**本次宿主环境对实际右键注册及真实“发送到”位置的重试均被 ACL／权限拒绝，检查未留下安装残留。** 因而不能声称这些入口已在此环境成功；部分 Windows／企业环境也可能失败，先使用按钮、拖放或可用快捷键。Windows 11 的传统右键项可能在“显示更多选项”中。可选手动安装器尚未提供。

卸载时：先在设置撤销曾启用的续页入口；从托盘完全退出（关主窗口可能只收进托盘）；再删除程序目录。默认保留仓库与导出备份，只有明确不再需要才自行删除。若仓库放在程序目录内，先移出数据。撤销被权限拒绝时请联系设备管理员，不要批量清理注册表。

续页保存工作线索，不是系统快照：不能恢复其他应用未保存的编辑、光标或窗口布局，也不保证所有操作系统／应用完美集成。当前没有 Android 版或跨设备自动同步。
