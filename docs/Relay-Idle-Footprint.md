# 原生常驻空闲资源实测

## 方法

2026-09-30 16:06–16:18，在当前Windows主机启动当时发布的自包含Relay，使用独立空仓库，启动后等待5秒，将其自己的主窗口最小化。之后720.008秒内每60秒采样一次，共基线+12个间隔。无卡片、无提醒、无专注、无诊断截图；后台同时有另一个数据耐久测试，属于共享主机测量。

[测量脚本](<../scripts/Test-IdleFootprint.ps1>) · [原始报告](<../artifacts/idle-test/4a218e5be60f4b60b260f1182d94fbca/report.json>) · [采样序列](<../artifacts/idle-test/4a218e5be60f4b60b260f1182d94fbca/series.json>)

## 结果

- 12分钟累计CPU时间 **3.703秒**。
- 相对单核心平均 **0.514%**；按本机8逻辑处理器归一化 **0.0643%**。
- 首分钟占3.578秒；后续11分钟总共约0.125秒。早期初始化与稳定空闲不应混为一谈，未做采样栈归因。
- 最后私有内存 **69,623,808字节，约66.4MiB**；基线54,358,016字节。
- 最后工作集 **259,268,608字节，约247.3MiB**；峰值与共享映射/操作系统调度相关，不能用私有内存替代这个实际工作集数值。
- 句柄568→580，末期稳定；线程21→11。
- 前后模块名称中未观察到WebView/Electron；这与纯WPF构建一致，但仅模块名称不构成系统级网络/子进程证明。
- 空仓库最终只有预期的锁文件，没有捕捉内容或活动记录。测试拥有的进程已结束，清理无错误。

## 不能推导什么

不是续航测试，不代表所有电脑都如此，不证明多年运行无泄漏，也不是“零CPU”“极低内存”的营销数字。这个工具有真实WPF/.NET常驻成本，是否值得常驻应以你的设备体验决定。
